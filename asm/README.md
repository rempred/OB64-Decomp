# asm

MIPS assembly source and reference disassembly.

- `original/` - generated original MIPS disassembly. This is the readable MIPS
  representation of the ROM.
- `nonmatching/` - assembly linked while corresponding C is not matching yet.
- `handwritten/` - hand-authored assembly shims or support code.
- `macros/` - shared assembly macros and include files.
