# Chunk 14 — MIXED: graphics data + display-list-builder code (`0x000E1000..0x000F1000`)

Source-ownership pass for the fifteenth 64 KiB chunk. **MIXED, heavily interleaved**:
leading graphics/display-list DATA, then CODE (display-list builders) with an
embedded pointer-table data island, then more CODE ending in an outgoing FUNCTION
straddler. **94 tracked parts**: **74 code (73 `func_*` + 1 straddler-head) + 20
data**. Byte-exact rebuild preserved (code SHA `40D4E787…B409`, ROM SHA
`571E8339…CC67A`). Coverage `0x1000..0xF1000` = 983,040 B = **34.5018 %** of the
2,849,204-byte evidenced executable extent; code-only classified ≈ 808,576 B
(**28.38 %**).

An 8-agent swarm (5 code-analysis + 3 data-classification) + a 4-agent adversarial
swarm. **Two boundary corrections** the adversarial/data pass caught: the data→code
boundary is `0xE48F0` (not the parent's first framed fn `0xE4BE0` — there are 3
frameless display-list-builder functions before it), and a preamble-orphan true entry
`0xEBBB0` (not `0xEBBC0`).
