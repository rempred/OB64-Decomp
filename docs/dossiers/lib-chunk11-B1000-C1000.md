analysis swarm at every `jr $ra`/`jr $reg`+delay→fresh-entry boundary. Highlights:
- **Four frameless-leaf gap clusters** (parent reported as leading gaps):

  - gap2 `0xB86F8` (the parent mislabeled this — see §Mistakes; 2 functions here).

  - gap4 `0xBA2B4..0xBA984` (4 leaves) — `move $t4,$a0`/`lui 0xFFFF` bitmask helpers.

  (e.g. the `0xB9014..0xB9234` field-setter cluster, the `0xBE820..0xBEB18`
  accessor cluster). A 12-byte frameless getter `func_000bbad0` (`lui 0x8019; jr $ra;

## Mistakes found and corrected (all caught by gates/adversarial pass)
- **2 delay-slot leaks** (gap4, caught by `check_boundaries`): the analysis agent
  ended `func_000ba790` and `func_000ba8a8` on their `jr $ra` instead of the delay
  slot. Fixed: boundaries shifted +1 word (`0xBA8A4`→`0xBA8A8`, `0xBA914`→`0xBA918`).
- **1 under-split** (adversarial): `func_000b86f8` hid a second function at `0xB876C`
  (a frameless entry reading `$a2/$a0/$a1` read-before-write, externally called, not
  reachable from the preceding function which returns `jr $ra`@`0xB8764`). Split into
  `func_000b86f8 [0xB86F8,0xB876C)` + `func_000b876c [0xB876C,0xB8794)`.
- **2 missed preamble-orphans** (adversarial): the analysis agent described the folds
  in its notes but never moved the boundaries. `func_000bedb8` (true entry `0xBEDB8`,
  was `0xBEDC0`) and `func_000bf248` (true entry `0xBF248`, was `0xBF250`) — each an
  8-byte `lui/lw 0x80196AF8` read-before-write preamble. Boundaries shifted back 8 B.
