## Method & verification

Pipeline: `dump_function_context` → `plan_chunk`/`slice_chunk` (code region, via
new `--disasm` override) → 6-agent code analysis swarm; 2-agent data-classification
swarm (`build/wf_data.js`); combine → `tools/check_boundaries.js` → 5-region

real issues (both fixed): (1) the straddler-tail was itself over-merged (see
above); (2) `rodata_0005ce70`'s last 8 bytes were the `0x5CEBC` order table, not
string pad. Gates: `check_manifest` ALL PASS; `check_boundaries` PASS;
`assemble_original_mips` byte-exact; `verify_setup` PASS; `audit_code_region` OK.
