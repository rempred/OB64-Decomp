# Chunk 6 — game data + PARENT-UNDETECTED code + data tail (`0x00061000..0x00071000`)

Source-ownership pass for the seventh 64 KiB chunk. **MIXED and three-part**:
DATA `0x61000..0x66E10` (item/equipment data) → **parent-undetected CODE**
`0x66E10..0x70E70` → DATA `0x70E70..0x71000` (straddles into chunk 7).
**78 tracked parts**: **60 code `func_*` + 18 data** (11 in DATA1, 6 inline islands
inside the code region, 1 in DATA2). Byte-exact rebuild preserved (code SHA
`40D4E787…B409`, ROM SHA `571E8339…CC67A`). Coverage `0x1000..0x71000` =
458,752 B = **16.10 %** of the 2,849,204-byte executable extent.

## Key discovery: a parent-detection gap

The parent function DB and the overlay map both have **0 entries** in chunks 6–7:
the last detected function before here is `0x5C1A8` (chunk 5) and the next is
`0x79730` (chunk 8). So the code in `0x66E10..0x70E70` is **parent-undetected** —
function boundaries were found from the disassembly, not the parent DB, using the
new `tools/scan_functions.js` (prologue-based seed: a `addiu $sp,$sp,-N` only
appears at a function entry) + the analysis swarm for frameless-leaf recovery.

## CODE `0x66E10..0x70E70` (60 `func_*` + 6 inline data islands)

Parent-undetected overlay code → all conservative `func_*`. The swarm recovered
frameless leaves and folded read-before-write preamble-orphans (heavy in this
chunk — many functions are preceded by a 2-word global-load preamble; 4 found by
the analysis swarm, 3 more by the adversarial pass). Six **inline data islands**
(pointer tables) interrupt the code and are emitted as `kind:"data"`:
`data_000694b0`, `table_00069618` (~166 RAM-pointer words), `data_000698dc`, and
the `0x6E5xx` island family — verified non-code (RAM-pointer words), surrounded by
functions. Deterministic invariants over all 60 code parts: 0 fragments, 0
cross-boundary branches, 0 under-splits, 0 delay-slot leaks.

## DATA2 `0x70E70..0x71000` (1 part) — straddles into chunk 7

`data_00070e70`: a ~400-byte non-CPU-code blob — a RAM pointer (`0x8019A590`) then

## Method & verification

`scan_functions` (prologue seed) → `slice_chunk --disasm` (code region) → 6-agent
code swarm; 2-agent data swarm (DATA1 + DATA2); combine → `check_boundaries` →
5-region adversarial swarm → 6 fixes (3 preamble folds, 1 data→table rename, 1
code-in-data recovery at `0x6E660`, 1 data-part merge). Gates: `check_manifest`
ALL PASS; `check_boundaries` PASS; `assemble_original_mips` byte-exact;
`verify_setup` PASS; `audit_code_region` OK. Tool changes: NEW
`tools/scan_functions.js`; `integrate_chunk.js` now tolerates a missing context
(parent-undetected regions).
