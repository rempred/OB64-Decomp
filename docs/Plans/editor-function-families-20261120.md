# Editor requests for matching C

These are the Editor Director’s six requested families for US Rev 0. **The OB64 Decomp team has claimed the 33 functions in the [army record ownership roster](army-record-ownership-program.md#wave-membership).** Mission suspend/restore is the highest-priority open family. Story sound is the smallest standalone target. For other targets, check the [current queue](../NEXT_STEPS.md) and coordinate claims through the [contributor guide](../../CONTRIBUTING.md#find-or-request-a-target).

**Sound command `0x6F`.** The accepted dispatcher and wrapper now carry both context selection and signed 32-bit gain through to the chosen resident service. All 48 tested context/value combinations reproduced the original gain on the rebuilt ROM. The Editor Director has the corrected source for host playback and export. The separate `0x6E` request-handler target in the table remains open.
