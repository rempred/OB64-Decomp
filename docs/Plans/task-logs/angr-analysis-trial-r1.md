## Concrete provenance and limitations

At CF0+4AC/+C4C, the real `lui a0,0x801D` precedes `lw a0,-0x1744(a0)` at +4B0/+C50, loading 801CE8BC after the allocator calls at +4A4/+C44. Only then do +4B4/+C54 save returned v0 to s0. `selected-rda-provenance.json` binds those definitions and their outgoing a1 uses. RDA's call-return definitions have synthetic statement index -2 and locations at the call delay instruction; they are analysis nodes, not instructions defining v0 there. Its generic return dependency also mentions other argument registers, which must not be interpreted as actual allocator semantics. The global-load predecessors in this run establish address provenance but not a complete memory-value/effect history. The independent oracle and fresh m2c already expose allocator result, owner load and copy size 6094. Nothing here proves moving an owner load before allocation safe or explains a new pinned-compiler scheduling remedy.

The bounded CFGs do not load external callees. Their graph represents continuation with `Ijk_FakeRet`; a post-freeze `get_call_sites()` query returns no call-site records in these blob configurations, even though raw code has respectively 0, 3, 5 and 57 JAL words. Raw instruction decoding and RDA/AIL call handling must not be mislabeled as a recovered complete interprocedural callgraph. The CF0 raw CFG has 177 nodes/244 edges, one owner and no reported unresolved indirect jump; that is not proof of whole-function execution fidelity or global effects.

`symbolic-bff8.json` records two 16-step-limited runs with explicit a0/sp/ra, a valid non-null address, a symbolic 32-bit word and a 1000ms solver timeout. Other machine state remains unconstrained; no hooks or zero-fill shortcuts were used. `symbolic-197c.json` records 20-step-limited runs with explicit state/output addresses and only the initial halfword supplied. These are synthetic input analyses of actual code, not runtime traces. No external call was executed or modeled. Full CF0 symbolic execution was not attempted past unsupported FCSR/callee effects; the selected-RDA query answers only the bounded static portion of the blocker question.

These setup failures remain in logs.

The selected MIPS32 big-endian architecture matches the observed 32-bit pointer and word-oriented argument operations, but does not certify all VR4300 physical 64-bit behavior. Every one of 1,141 selected code words is covered by lifting with sufficient delay-slot lookahead. Initial one-instruction calls falsely reported branches as NoDecode; corrected `lift-r2` checks coverage of the first word with two-instruction lookahead, retaining the failed harness outputs. No bytes were changed. MIPS64 also lifts the 850 CF0 words, but its default generic N64 calling convention means the MIPS n64 ABI, not Nintendo 64's observed o32-like convention. It cannot be substituted silently. No wide-integer instruction example was added, so wide-register fidelity remains untested.

Actual FP IR uses paired low halves for doubles in the MIPS32 model (e.g. f2/f3 after `ldc1`), consistent with an FR0-style representation, but this is not full hardware validation. At runtime address 801D2CDC (CF0+2BC, word 46000021), `cvt.d.s` emits the unsupported FCSR helper. The finite/NaN vectors cannot reach the comparison or its delay-slot store; no result for rounding, exceptions, NaNs or hardware FCSR behavior is claimed. CP0, DMA, hardware state, mutable overlays and arbitrary external code are outside this trial.

All analysis processes have recorded wall limits (30–60 seconds for individual analysis runs); RDA additionally uses three iterations and bounded element sets. No analysis timed out. Successful executable analysis processes generally took a few seconds including import overhead; fresh m2c runs took 0.28–0.47 seconds. End-to-end research, loader/API work, reference comparison and reporting took roughly half an hour, not just solver time. Maintaining a reliable optional interface would require accepted segment/table mapping, explicit query assumptions, call-effect/prototype handling, output checks and a solution or fail-closed boundary for FCSR. This bounded sample did not establish a benefit sufficient to justify that shared integration cost.
