## Decisive drawing-pointer result

Retail loads a render pointer into `s1` and later loads a size pointer into `s0`. The shared stores use retained `s1` at offsets 8 and 12.

Kuna preserves this distinction as `v19[2]` and `v19[3]`, followed by separate size stores through `v18`.

Fresh raw m2c instead prints the shared stores through the current cursor global. That global was already advanced from the retained render pointer.

This difference changes the printed address relation. It is not a variable-renaming difference.

The current D037 source uses separate `companionCommand` and `companionSizeCommand` pointers. It already expresses the useful Kuna interpretation.

The review also reproduced Kuna's separate packed endpoints, signed tile correction, and flipped-row clamp. Those facts already exist in project evidence.
